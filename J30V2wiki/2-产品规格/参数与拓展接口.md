## 基本参数

| 参数 | 规格 |
| --- | --- |
| 重量 | 2128g（无桨保）、1420g（无电池） |
| 尺寸 | 376×422×186mm（无桨保） |
| 对角线轴距 | 314mm |
| 最长悬停 | 最高16min|
| 最大起飞重量 | 3kg |
| 外壳材料 | PC/ABS（高强度工程塑料） |
| 工作温度 | 0°C~40°C |
| 抗风等级 | 3级风 |
| 系统环境 | Ubuntu 20.04 / ROS noetic |
| 选配传感器 | 单目相机/双目相机 |

| --- | --- |
| 激光波长 | 905nm |
| 近处盲区 | 0.1m |
| FOV | 水平360°、竖直-7°~52° |
| IMU | 内置IMU型号ICM4060 |
| 点云输出 | 20万点/秒 |
| 点云帧率 | 10HZ |
| 测距随机误差(1σ) | ≤2cm (@10m)、≤3cm (@0.2m) |
