# 视觉定位测试（双目相机）

!!! info "📖 本章导读"
    * **双目视觉定位测试**仅用于首次拿到无人机后，测试双目视觉定位是否准确
    * 本章仅适用于 **选配了双目相机（D435）** 的用户
    * 请先完成[雷达定位测试](雷达定位.md)中的基础流程，再来看本章

**什么是视觉定位？** 与雷达用激光"看"环境不同，视觉定位使用双目相机像人的两只眼睛一样观察环境，通过两个镜头画面的视差计算深度，从而确定无人机的位置。它适合特征丰富的室内环境，但对环境纹理要求较高。

!!! warning "⚠️ 注意"
    * 视觉定位对环境特征要求较高，尽量在飞行场地多放一些障碍物增加视觉特征点，避免单一颜色的背景
    * 使用自主功能模块前请务必完成[自主飞行前准备](../../1-快速上手/首次手动飞行.md)并确保飞手具备基本的手动操控能力

1. 检查配置文件 `Diff-Navigation/config/navigation_config.yaml`，将 `localization_mode` 参数修改为 `vio`，定位模式切换为视觉定位。

2. 将无人机放置于地面，并标记好起始位置，执行以下命令启动程序：

```bash
cd ~/Diff-Navigation
./sh_files/navigation.sh
```

3. 等待约50秒，程序完全启动后将自动打开 monitor 用户交互界面，并同时启动 RViz 可视化窗口。

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/images/modules/vio_test/vio_test_p7.jpg" width="1000" />

5. **检查相机内参**。新建一个窗口，执行以下命令查看双目相机内参，消息中的 K 矩阵即为深度相机内参，注意矩阵中的顺序为 fx/cx/fy/cy：

```bash
cd ~/Diff-Navigation
rostopic echo /camera/depth/camera_info
```

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/images/modules/vio_test/vio_test_p8.png" width="1000" />

将打印出的内参与配置文件 `Diff-Navigation/config/navigation_config.yaml` 中 `camera` 参数进行比对，检查是否一致，如果不一致，按照打印出来的参数进行修改（修改时注意参数顺序）。

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/images/modules/vio_test/vio_test_p9.png" width="1000" />

>**当相机内参不正确时，会发生什么？**
相机内参（K 矩阵中的 fx/fy/cx/cy）是像素与真实世界之间的换算基准。内参不正确时，所有基于图像的测量都会出现系统性偏差，具体表现为：

| 受影响功能 | 典型症状 |
| --- | --- |
| 深度测距 | 距离值整体偏大或偏小，且距离越远误差越大 |
| 光流悬停 | 悬停时朝固定方向缓慢漂移，或位置来回震荡、定不住 |
| SLAM/定位 | 轨迹比例失真，飞封闭路线回不到起点，地图中直线墙体变弯 |
| 三维点云 | 平面墙体重建后呈弧形弯曲，障碍物位置整体偏移 |

>**如何区分内参问题与环境问题**：纹理、光照导致的光流异常只在特定地面环境下出现；内参异常则在所有环境下都存在、偏差方向固定、且随距离增大而放大。如果设备在各种场地都出现「悬不住、测距总是偏一点」的情况，请优先检查相机内参，必要时重新标定。

6. 手持无人机，绕飞行场地缓慢移动。移动过程中，可观察到 monitor 界面中的位置数据和 RViz 中的无人机坐标系同步变化。绕场一周后，将无人机放回原位（标记的起始点）。此时再次查看 monitor 界面中的定位数据，若当前位置坐标偏差在合理范围内（≤0.2m），则说明视觉定位稳定可靠。
