# 自主目标跟踪（Elastic Tracker）

!!! info "📖 本章导读"
    本章介绍如何让无人机自主识别并跟踪目标（二维码）。内容包括两个部分：

    1. **单目视觉检测测试**：验证二维码检测功能是否正常工作
    2. **自主目标跟踪飞行**：启动跟踪程序，让无人机跟随目标移动

**原理简介**：在目标上粘贴二维码（AprilTag），无人机用单目相机识别二维码的位置，并自动保持距离跟随目标移动。就像"无人机版的自动跟拍镜头"。

**算法简介**：Elastic Tracker 是一个面向空中机器人（无人机）视觉目标跟踪的时空轨迹规划框架，由浙江大学 FAST Lab 开发，发表于 ICRA 2022（论文：*Elastic Tracker: A Spatio-temporal Trajectory Planner for Flexible Aerial Tracking*，作者 Jialin Ji、Neng Pan、Chao Xu、Fei Gao）。

Elastic Tracker 解决无人机在复杂障碍环境中跟踪移动目标时的核心矛盾：跟踪精度、目标可见性与飞行安全三者难以同时满足。框架允许无人机在必要时弹性地偏离理想跟踪位置，以换取安全保障和目标可见性，待条件恢复后再回到跟踪状态，因此称为"弹性"跟踪。

**框架组成**：
- **目标检测与意图无关的运动预测**：不依赖目标意图假设，直接预测目标未来运动轨迹。
- **遮挡感知的路径搜索**：前端路径搜索同时考虑避障与目标可见性，生成合适的引导路径拓扑。
- **安全飞行走廊生成**：沿引导路径构建安全飞行走廊（基于 DecompROS）。
- **时空轨迹优化**：在走廊内进行时空联合轨迹优化，将安全性与可见性纳入统一目标函数，其中可见性通过解析遮挡代价评估，轨迹采用 MINCO 表示。

## 一、单目视觉检测测试

> 💡 本章需要**视觉追踪选配包**（单目摄像头 + 二维码），并确认已通过[雷达定位测试](定位测试/雷达定位.md)。

1. 将无人机放置于桌面，进入 `Elastic-Tracker` 工作空间，启动追踪脚本：

```bash
cd ~/Elastic-Tracker
./sh_files/run_all.sh
```

2. 使用 `rqt_image_view` 指令打开图像可视化工具，选择 `/usb_cam/image_raw` 图像话题即可看到单目相机图像画面。

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image49.png" width="900" />

> 若启动相机驱动过程中出现 <span style="color:red;">Error starting device</span> 错误，或者 `/usb_cam/image_raw` 话题对应图像源不是单目的，需要检查 `Elastic-Tracker/src/other-lib/usb_cam/launch/usb_cam.launch` 文件中 `video_device` 对应的端口号是否对应USB相机占用端口。

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image50.png" width="900" />

3. 在 `rqt_image_view` 中查看 `/tag_detections_image` 话题图像，并将事先打印好的二维码放到相机前，查看是否能稳定识别到二维码（标记为红框）。

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image52.png" width="900" />

二维码的种类和尺寸分别在 `Elastic-Tracker/src/detection/apriltag_ros/apriltag_ros/config` 文件夹下的 `settings.yaml` 和 `tags.yaml` 中设置：

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image53.png" height="300" />
<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image54.png" height="300" />

二维码图片下载和尺寸测量方法参考：[apriltag](https://github.com/AprilRobotics/apriltag?tab=readme-ov-file#choosing-a-tag-family)。
也可直接点击 [tag26h11](https://diffrobots.oss-cn-hangzhou.aliyuncs.com/j30-wiki/extra/tag36h11.pdf) 下载本例中使用的二维码图像，打印时注意长宽比和图片中保持一致，并测量实物尺寸后填入 `tags.yaml`。

## 二、自主目标跟踪飞行

!!! warning "⚠️ 注意"
    进行前请先完成[雷达定位测试](定位测试/雷达定位.md)和[单目视觉检测测试](#一单目视觉检测测试)，确保都没有问题再进行。

1. 检查 `Elastic-Tracker/src/planning/planning/launch/run_exp_tag.launch` 中各追踪参数是否设置合适：

| 参数名 | 参数值 | 说明 |
| --- | --- | --- |
| tracking_dist_ | 2.5 | 期望追踪距离（无人机与目标的保持距离） |
| vmax_ | 1.5 | 最大追踪速度 |
| amax_ | 1.5 | 最大追踪加速度 |
| prediction_vmax_ | 4.0 | 目标最大预测速度 |
| target_add_z_ | 0.0 | 目标高度偏置 |

2. 检查 `Elastic-Tracker/src/realflight_modules/px4ctrl/config/ctrl_param_fpv.yaml` 中起飞高度 `takeoff_height` 设置是否合适。

3. 检查 `Elastic-Tracker/src/user_command/multipoint/launch/multipointplan_exp.launch` 中 `auto_planning` 参数。如果 `auto_planning` 设为 `true`，无人机起飞并悬停后将自动开始跟踪。如果 `auto_planning` 设为 `false`，无人机起飞悬停后需手动按下遥控器 SD 键触发跟踪。

4. 将无人机放置于安全、平整地面，以无人机为中心半径50cm的四周请勿放置任何障碍物。打开遥控器，SC键切换成解锁模式，将左侧摇杆保持中位，右侧摇杆保持中位，将SB键切换到自主飞行模式（一档），SE键保持弹出状态。

5. 进入 `Elastic-Tracker` 工作空间并启动自主跟踪脚本：

```bash
cd ~/Elastic-Tracker
./sh_files/run_all.sh
```

程序启动后 rviz 界面所示：

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image63.png" width="900" />

!!! warning "⚠️ 注意"
    * 程序启动完成前，请勿移动无人机，否则会导致定位出错

6. 将贴有二维码的目标就位至无人机前适当距离处（期望追踪距离附近），查看 rviz 中目标位置是否出现（可通过 `rostopic echo /target_ekf_odom` 查看是否有消息输出），也可打开 `rqt_image_view` 实时查看检测效果。

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image64.png" height="340" />
<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image65.png" height="340" />

7. **开始跟踪**：

- **方式一：自动触发跟踪**（`auto_planning=true`）。按下 SD 键，此时无人机会自主起飞至设定高度，然后开始自动追踪二维码。
- **方式二：手动触发跟踪**（`auto_planning=false`）。按下 SD 键，此时无人机会自主起飞至设定高度。第二次按下 SD 键，无人机开始自动追踪二维码。

!!! warning "⚠️ 注意"
    * 目标移动速度不能超过设定的最大追踪速度
    * 移动过程中尽量使二维码正对飞机相机，尽量匀速运动，避免急停急走
    * 转弯时要慢，确保飞机始终能正视二维码
    * 若跟丢，把二维码重新放回飞机视野中可重新开始追踪
    * 若跟踪过程中出现撞到障碍物、与目标过近等意外，在飞行未失控情况下及时将6通打至上档进入悬停
    * 不要在无人机下方有障碍物时降低目标高度；不要在无人机后方有障碍物时后退，否则可能会导致无人机炸机

8. 跟踪结束后，按下遥控器 SE 键，切换为悬停模式。待悬停稳定后将无人机操控至可降落区域，缓慢下降油门，无人机缓慢降落。待飞机安全着陆后，将SC键切换为上锁模式，并在任务终端输入 `ctrl+c` 结束程序。
