# 常见问题解答（FAQ）

!!! info "📖 本章导读"
    * 本章按类别整理高频问题与解决方法，遇到问题先在这里查找
    * 如果这里没有答案，可查看[异常处置](异常处置.md)或联系[售后服务](../6-维护与支持/售后服务.md)

## 一、基本配置

**1. 如何获取双目驱动、单目驱动、飞控固件等下载资料？**
请先查看[售后服务 - 常用下载](../6-维护与支持/售后服务.md)章节是否有对应资源，如没有可联系售后。

**2. 电脑登陆密码是什么？**
`nv`

**3. 雷达IP是多少？**
通常被设置为 192.168.2.88，可通过 `ping 192.168.2.88` 来测试。

**4. 接收不到雷达点云数据？**
① 检查雷达是否在工作，工作时会有声音且能感受到雷达在振动
② 检查雷达通讯是否正常：在终端输入 `ping 192.168.2.88` 看是否能ping通，若无法ping通检查 NX 的 PCI 有线网 ip 是否为 192.168.2.50；若是，检查 wifi 网段是否也是 2.x，也是 2.x 的话会导致与雷达网关冲突，需要更改路由器 IP。

**5. 无人机内部物理传感器的安装位置信息在哪里查看？包括机体坐标系（body）、基准坐标系（base_link）、Livox 雷达坐标系（livox_frame）、PX4 IMU 坐标系之间的静态坐标变换（static tf）。另外，机体坐标系（body frame）在无人机上的实际物理位置是如何定义的？**
无人机的飞控IMU位置被视作机体坐标系（body frame）的原点。激光雷达坐标系（lidar frame）与机体坐标系原点之间的转换矩阵和平移矩阵，可在文件 `Diff-Planner/src/realflight_modules/faster-lio/config/mid360.yaml` 中找到。其中，`extrinsic_T` 和 `extrinsic_R` 分别表示激光雷达相对于其内置IMU的平移矩阵与旋转矩阵，`world_transform_T` 和 `world_transform_R` 则分别表示雷达内置IMU相对于机体坐标系的平移矩阵与旋转矩阵。

**6. 终端显示 `zsh: corrupt history file /home/nv/.zsh_history`，是什么原因？**

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/102.png" height="200" />

强行关机会这样，删掉这个报错文件即可：`rm /home/nv/.zsh_history`

**7. 启动程序后终端输出以下内容是什么原因？**

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/images/faq/p1.png" height="200" />

ROS 在运行过程中，会自动把各种运行日志保存在 `~/.ros/log` 这个文件夹里。时间一长，或者经过多次调试运行，这些日志文件会越积越多，占用的磁盘空间超过了 1GB 的默认提醒阈值。这条警告不会阻止你的程序正常启动和运行，可以忽略。

**8. 如何重置/恢复工作空间（程序被改坏了想恢复出厂状态）？**

如果误删文件或修改代码导致程序无法正常运行，可以按以下步骤快速恢复干净的工作空间：

1. 删除原有的工作空间目录（如 `rm -rf ~/Diff-Navigation`）
2. 重新从官方仓库拉取代码：`git clone --recursive <仓库地址>`
3. 重新编译：`cd <工作空间> && catkin_make`

此方法适用于所有工作空间（Diff-Navigation、Elastic-Tracker、Diff-YOPO、YOLO 等）。
【教程指引】[代码获取与维护 - 官方代码拉取与编译](../4-二次开发/代码获取与维护.md)

## 二、硬件相关

**1. 飞机通过转接线连接到电脑显示屏没有反应是怎么回事？**
① 检查是否上电
② 检查是否配过热点连接，导致 NX 端有线 IP 变了
③ 检查是否接错线

**2. 接电后风扇不转，NX无输出，是怎么回事？**
请排查以下情况：
① 拆壳检查内部是否摔坏
② 检查连接显示屏顺序，先连显示屏再上电
③ 看机载电脑电路板的左右2颗绿灯能否正常亮起，若不亮则检查：
&emsp;a. 万用表测量XT30接口看供电是否正常
&emsp;b. 载板的核心板连接器引脚有没有断裂

**3. 系统显示过热警告：Caution - Hot surface. Do not touch 怎么办？**
系统运行时芯片温度升高，属于正常警告信息，若没有出现明显卡顿情况可忽略。

**4. 充电器设置正确，但是点击开始充电任务时播报"显示不支持此类操作"**
排查步骤：
① 检查电池与充电器是否连接正确
② 若连接正确，更换充电通道看是否能正常充电
③ 若两个通道都有问题，更换电池看是否能正常充电
若以上步骤均失败，常见原因为充电器内部元器件损坏，可返厂更换全新充电器。

**5. 遥控器与无人机连接不上**
① 检查无人机与遥控器SN是否一致
② 检查遥控器和无人机是否都上电

**6. 收到货后发现没有显卡欺骗器**
更新后的产品已经不需要欺骗器，可参考最新版[发货清单](../1-快速上手/开箱与发货清单.md)。

**7. 如何查看无人机剩余电量？**
启动 mavros 后使用 `rostopic echo /mavros/battery` 查看电池电压，满电情况下（25V左右）能飞行18分钟以上，21V以下建议充电，此时仅能飞行3分钟左右，建议起飞前先查看一下电池电量。
【教程指引】[指令速查手册 - 状态查看](指令速查手册.md#四状态查看与排障)

**8. 供电口插入供电声音很大，是正常的吗？**
正常的，蜂鸣器会发出声音是正常现象，用于提醒无人机正在运行。
【教程指引】[充电与遥控器](../1-快速上手/充电与遥控器.md)

**9. 点云数据使用网口传输，如果要使用这个数据可以通过网口透传吗？**
可以。

**10. 网口有没有加前置变压器？不加变压器隔离，直接接设备会不会损坏PHY芯片？**
没有使用前置变压器，但我们通过在信号端串联电容的方式实现了隔直流通交流，保证了信号的正常传输。在我们目前的短距离测试环境下，能正常使用没有出现损坏PHY芯片的情况。

## 三、手动飞行相关

**1. 手动飞行模式下无人机无法解锁**
按以下顺序逐条检查测试：
① 检查无人机与遥控器SN是否一致
② 检查遥控器和无人机是否都上电
③ 检查遥控器拨杆以及解锁方式是否正确【教程指引】[充电与遥控器 - 遥控器介绍](../1-快速上手/充电与遥控器.md)
④ 以上检查均确定无误后还是无法手动解锁，可将无人机电池下电后重新上电再尝试手动解锁
⑤ 重新上电后还是无法解锁，可在机载电脑启动 mavros 后再手动解锁，查看 mavros 终端输出，并将报错信息发送至售后群联系售后进一步排查：

```bash
#启动mavros指令
sudo chmod 777 /dev/tty*
roslaunch mavros px4.launch
```

**2. 解锁后飞不起来是怎么回事？**
① 检查通道设置并内八解锁
② 手飞时建议采用光流模式，高度3m内，选择地面纹理清晰的场景，姿态模式油门响应灵敏，需要有一定的手飞熟练度
【教程指引】[首次手动飞行](../1-快速上手/首次手动飞行.md)

## 四、自主飞行功能相关

**1. 飞控的主航向源是什么？**
飞控没有磁力计，主要靠激光雷达定位算法。

**2. 启动自主飞行程序后 rviz 中未出现无人机位置/栅格地图，是怎么回事？**
① 检查点云数据是否正常：在新终端输入 `rostopic echo /laserMapping/cloud_registered` 查看是否有输出
② 检查imu数据是否正常：在新终端输入 `rostopic echo /mavros/imu/data` 查看是否有输出
③ 检查定位是否正常：在新终端输入 `rostopic echo /ekf/ekf_odom` 查看是否有输出
④ 以上都有输出时检查 rviz 配置是否正确、终端是否有红色报错

**3. rviz可视化点云时系统卡顿明显怎么办？**
可视化点云话题时 decay time 设置太大，导致过多点云残存，占用内存过多，将该话题可视化关闭或减小 decay time（如设置为100）。

**4. Diff-Planner自主规划时，起飞悬停后下达开始任务指令无人机没反应；执行任务中途无人机到达中间途径点后进入悬停，不飞往下一个途径点**
实时处理方法：[异常处置 - 规划出错](异常处置.md)
排查方法：
① 检查终端是否出现报错，若出现 `"replan fail too much. Emergency stop."` 说明规划失败了，需要检查规划参数是否合理、障碍物摆放是否过于密集
② 检查各点位是否超出设置的虚拟天花板/地板范围；检查各点位是否设置在障碍物中/过于靠近障碍物处

**5. 单目视觉在运行时注意事项**
单目跟踪时要注意此时雷达是单帧避障，处于雷达感知盲区无法识别会撞击障碍物，建议移动二维码时要注意。

**6. 使用自主飞行功能时通过遥控器发送起飞指令无人机无法解锁**
按以下顺序逐条检查测试：
① 检查终端输出，若出现 `Reject AUTO_TAKEOFF. If you have your RC connected, keep its switches at...`（未进入轨迹跟随模式）或 `ARM rejected by PX4! Kill-switch activated?`（急停未开）请检查遥控器各通道是否正确，若不正确，重新调整后重新启动程序尝试起飞
② 向上翻动终端输出或重新启动程序，检查是否出现红色报错（以下报错是由于ros日志文件积累过多不影响程序：`WARNING: disk usage in log directory [/home/nv/.ros/log] is over 1GB.`），若有报错且无法解决可将截图发至售后群让售后帮忙分析
③ 将遥控器通道调整为手动飞行模式，检查是否能手动解锁【[手动解锁/上锁测试](../1-快速上手/首次手动飞行.md)】，若不能跳转至[手动飞行相关：问题1](#三手动飞行相关)
④ 若按以上步骤排查完后依然无法起飞请联系售后进一步分析

**7. 如何实时查看、保存生成的点云？**
① 雷达定位导航规划：启动 diff-planner 后通过在 rviz 设置点云话题的 decay time 查看累积点云地图
② 保存生成的点云方法：在 `Diff-Planner/src/realflight_modules/faster-lio/config/mid360.yaml` 文件中将 `pcd_save_en` 设置为 `true`，每次在终端 ctrl+c 程序结束后，点云 .pcd 文件会自动保存在 `Diff-Planner/src/realflight_modules/faster-lio/PCD` 目录下（需要保存地图时不要长时间运行程序，可能导致点云文件过大内存爆满）

**8. 雷达建图时是否可以去除无人机**
如去掉无人机容易误去掉障碍物，目前暂不支持。

**9. imu和mid360的数据时间如何同步？**
通过ROS时间戳同步，在 fasterlio 代码里面，没有硬同步。

**10. 终端反复输出 `[ERROR]: A negtive value of nearby obstacle number! reset the map.` 是什么原因？**
是一个BUG，可通过更新程序解决，不更新不影响正常使用。
【教程指引】[代码获取与维护](../4-二次开发/代码获取与维护.md)

**11. 终端输出 `Estimated hover_percentage >0.8 or <0.1! Perhaps the accel vibration is too high!` 是什么原因？**
遥控器通道在启动程序后有拨动就会这样，必须调整通道后重启程序。

## 五、仿真器使用

仿真器链接：https://github.com/DifferentialRobotics/Aerial_Autonomy_Challenge/tree/2026robotics

**1. 我在 github 上下载下来的仿真模拟中，并没有发现相机相关的配置，我打开了 sh_files 文件中的 run_vins.sh 文件，发现它实际并没有被执行到，是本身就没有配置还是需要后续打开新的终端额外执行呢?**
run_vins 是实机中启动 vins 定位用的，仿真中没有启动相机。

**2. 是否提供了无人机的模型本身，我打开了对应的 AerialAutonomyChallenge-Simulator_Data 的文件夹，发现里面大部分是已经被打包好 unity 的文件，实际上并不能直接编辑，我想将无人机模型拿出来单独放在一个我们新建的环境中能否做到？或者我们可能这样做吗?**
仿真环境是打包好的，不支持自己增加/获取模型。

**3. 我直接使用仿真模拟中的 target_ring 的功能，发现无人机确实能够精准的穿过圈，但是在动态障碍区有不小的概率会出现撞击的现象，运行10次会有大概30%的概率撞击1-2次，请问这个现象是否正常，后续应该如何优化?**
正常现象，可以修改最大飞行速度、地图分辨率、膨胀半径、轨迹优化安全距离裕量等来优化。

**4. 我在 diff_planner 中已经通过 ros 实现了无人机的四翼螺旋桨电机的PID控制，所以我们是否可以直接套用这些 ros 话题，来在未来适配我们自己的环境呢?**
没有实现电机的 PID 控制，仿真代码的控制方式不能用于实机，实机控制器见 https://github.com/DifferentialRobotics/px4ctrl

## 六、其他问题

**1. 无人机飞行环境限制说明**
禁飞场景：暗光环境（如日落后户外）、空旷场景、水面、飞行高度3m外无法飞行。
【教程指引】[安全须知与飞行前检查](../6-维护与支持/安全须知与飞行前检查.md)

**2. 光流注意事项**
① 使用时选择地面纹理清晰、光照充足的场景（光流传感器不适用于所有地面纹理，光滑反光面、水面等低纹理表面会导致光流失效）
② 飞行高度建议3m内
③ 起飞时拨到60%油门起飞后高度1m左右
④ YAW方向不要动
【教程指引】[首次手动飞行 - 光流悬停](../1-快速上手/首次手动飞行.md#第三步光流悬停飞行测试)
