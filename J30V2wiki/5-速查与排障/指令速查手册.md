## 三、基础服务与硬件驱动

```bash
# 启动 mavros（连接飞控，查看电量前需先启动）
sudo chmod 777 /dev/tty*
roslaunch mavros px4.launch

# 启动双目相机驱动（realsense）
cd Diff-Navigation
source devel/setup.zsh
roslaunch realsense2_camera rs_camera.launch

# 启动单目相机驱动
cd Elastic-Tracker
source devel/setup.zsh
roslaunch usb_cam usb_cam.launch

# 打开图像可视化工具
rqt_image_view
```

## 四、状态查看与排障

```bash
# 查看电池电压（低于 21V 建议充电）
rostopic echo /mavros/battery

# 查看雷达点云数据是否正常
rostopic echo /laserMapping/cloud_registered

# 查看 IMU 数据是否正常
rostopic echo /mavros/imu/data

# 查看定位结果是否正常
rostopic echo /ekf/ekf_odom

# 查看目标跟踪时的目标位置
rostopic echo /target_ekf_odom

# 查看双目相机内参（深度相机）
cd ~/Diff-Navigation
rostopic echo /camera/depth/camera_info

# 查看厂家标定的相机内参（左右目、深度）
rostopic echo /camera/infra1/camera_info
rostopic echo /camera/infra2/camera_info
rostopic echo /camera/depth/camera_info

# 查看机载电脑 IP
ifconfig
```

## 五、相机标定（kalibr）

```bash
# 录制双目标定 bag
rosbag record --tcpnodelay /camera/infra1/image_rect_raw /camera/infra2/image_rect_raw /mavros/imu/data

# 录制单目标定 bag
rosbag record --tcpnodelay /usb_cam/image_raw

# 双目相机内参标定（1970-01-01-08-08-54.bag 更换为实际的包名）
source devel/setup.bash
rosrun kalibr kalibr_calibrate_cameras --target april_6x6.yaml --bag 1970-01-01-08-08-54.bag --model pinhole-radtan pinhole-radtan --topics /camera/infra1/image_rect_raw /camera/infra2/image_rect_raw

# 双目相机外参标定（更换为实际的文件名）
rosrun kalibr kalibr_calibrate_imu_camera --target april_6x6.yaml --bag 1970-01-01-08-08-54.bag --cam 1970-01-01-08-08-54-camchain.yaml --imu mavros_imu.yaml --timeoffset-padding 0.1 --max-iter 20

# 参数转换为 VINS 格式（更换为实际的文件名）
python3 kalibr_to_vins.py --kalibr_file 1970-01-01-08-08-54-camchain-imucam.yaml --vins_calib_save_file_path fast_lab.yaml

# 单目相机内参标定
rosrun kalibr kalibr_calibrate_cameras --target april_6x6.yaml --bag 1970-01-01-08-08-54.bag --model pinhole-radtan --topics /usb_cam/image_raw
```

> 详细标定流程见[相机标定](相机标定.md)

## 六、集群时间同步

```bash
# 地面站开启 NTP
systemctl enable ntp
systemctl start ntp

# 无人机开启 NTP
sudo systemctl start ntp

# 无人机向地面站同步时间（IP 为地面站 IP）
sudo ntpdate -u 192.168.8.102
```
