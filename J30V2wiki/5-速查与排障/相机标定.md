# 单/双目相机标定教程

!!! info "📖 本章导读"
    * 相机标定用于校正相机内参（焦距、光心等）和外参（相机相对无人机的位置），确保定位精度
    * 相机在出厂时已由厂家标定，**建议优先使用厂商的标定结果**；只有在更换相机或需要重新标定时才执行本章操作

## 1. 双目相机标定

!!! warning "⚠️ 注意"
    1. 相机标定使用开源的 kalibr 程序进行
    2. kalibr 程序部署见：**标定程序部署** 章节
    3. 相机标定需要使用提供的标定文件，等比例缩放后自行计算
    4. 将标定文件打印出来后，纸张必须平整，没有任何褶皱
    5. 打印出来的标定文件图像越大，标定结果越准确
    6. 双目相机厂家已经对其进行标定，所以建议使用厂商的标定结果
    7. 官方的教程可见链接：[kalibr wiki](https://github.com/ethz-asl/kalibr/wiki)

### 1.1 双目标定 bag 录制

1. 使用 NoMachine 连接机载电脑。
2. 使用以下命令启动 mavros & 相机驱动程序：

```bash
# 第一个终端
sudo chmod 777 /dev/tty*
roslaunch mavros px4.launch

# 第二个终端
cd Diff-Navigation  # 有些飞机中的项目名可能会不一样，注意区分
source devel/setup.zsh
roslaunch realsense2_camera rs_camera.launch

# 第三个终端
rqt_image_view  # 打开相机画面
```

3. 使用以下命令录制 bag 包：

```bash
# 第四个终端
rosbag record --tcpnodelay /camera/infra1/image_rect_raw /camera/infra2/image_rect_raw /mavros/imu/data
```

### 1.2 开始标定

1. 复制 bag 包到 kalibr-ws 工程目录下。

2. 双目相机内参标定：

```bash
source devel/setup.bash

# 双目相机内参标定命令
# 1970-01-01-08-08-54.bag 更换为实际的包名
rosrun kalibr kalibr_calibrate_cameras --target april_6x6.yaml --bag 1970-01-01-08-08-54.bag --model pinhole-radtan pinhole-radtan --topics /camera/infra1/image_rect_raw /camera/infra2/image_rect_raw
```

3. 双目相机内参标定结果检查：
- 标定完成后会自动弹出报告，主要看 `cam0` 和 `cam1` 的 `reprojection errors`
- 相机的重投影误差在 0.5 以内，且分布比较均匀即可

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image104.png" width="430"/>
<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image105.png" width="430"/>

4. 双目相机外参标定：

```bash
source devel/setup.bash

# 双目相机外参标定命令
# 1970-01-01-08-08-54.bag 更换为实际的包名
# 1970-01-01-08-08-54-camchain.yaml  更换为实际的文件名
rosrun kalibr kalibr_calibrate_imu_camera --target april_6x6.yaml --bag 1970-01-01-08-08-54.bag --cam 1970-01-01-08-08-54-camchain.yaml --imu mavros_imu.yaml --timeoffset-padding 0.1 --max-iter 20
```

5. 双目相机外参标定结果检查：
- 主要看 `cam0` 和 `cam1` 的 `reprojection errors`，相机的重投影误差在 0.5 以内，且分布比较均匀即可

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image106.png" width="430"/>
<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image107.png" width="430"/>

### 1.3 参数转换

1. 使用以下命令，将参数转换为 VINS 使用的格式：

```bash
# 1970-01-01-08-08-54-camchain-imucam.yaml 更换为实际的文件名
python3 kalibr_to_vins.py --kalibr_file 1970-01-01-08-08-54-camchain-imucam.yaml --vins_calib_save_file_path fast_lab.yaml
```

### 1.4 双目相机内参获取（厂家标定的参数）

1. 使用 NoMachine 连接机载电脑。

2. 使用以下命令启动相机驱动程序：

```bash
# 打开一个终端，输入命令
cd Diff-Navigation  # 有些飞机中的项目名可能会不一样，注意区分
source devel/setup.zsh
roslaunch realsense2_camera rs_camera.launch
```

3. 使用以下命令输出厂家的标定完的参数：

```bash
# 输出左目的内参
rostopic echo /camera/infra1/camera_info

# 输出右目的内参
rostopic echo /camera/infra2/camera_info

# 输出深度的内参
rostopic echo /camera/depth/camera_info
```

4. 参数中，**K列表**的值为内参数据，数据对应关系为：
- fx：389.8578796386719
- cx：322.1803894042969
- fy：389.8578796386719
- cy：239.80404663085938

## 2. 单目相机标定

!!! warning "⚠️ 注意"
    1. 单目相机因无法用来定位，所以只需要标定内参即可
    2. 单目相机内参标定流程与双目相机的内参标定流程基本相同

### 2.1 单目标定 bag 录制

1. 使用 NoMachine 连接机载电脑。
2. 使用以下命令启动相机驱动程序：

```bash
# 第一个终端
cd Elastic-Tracker
source devel/setup.zsh
roslaunch usb_cam usb_cam.launch

# 第二个终端
rqt_image_view  # 打开相机画面
```

3. 使用以下命令录制 bag 包：

```bash
# 第三个终端
rosbag record --tcpnodelay /usb_cam/image_raw
```

### 2.2 开始标定

1. 复制 bag 包到 kalibr-ws 工程目录下。

2. 相机内参标定：

```bash
source devel/setup.bash

# 单目相机内参标定命令
# 1970-01-01-08-08-54.bag 更换为实际的包名
rosrun kalibr kalibr_calibrate_cameras --target april_6x6.yaml --bag 1970-01-01-08-08-54.bag --model pinhole-radtan --topics /usb_cam/image_raw
```

3. 内参数据检查：
- 标定完成后会自动弹出报告，主要看 `cam0` 的 `reprojection errors`，相机的重投影误差在 0.5 以内，且分布比较均匀即可

<img src="https://cdn.jsdelivr.net/gh/zionchenzhe-ops/test-wiki@main/J30V2wiki/manual_media/media/image104.png" width="430"/>

### 2.3 单目相机内参数据替换

1. 标定完成后会生成一个名为 `xxx-camchain.yaml` 的文件（xxx 为包的名字）。
2. 其中 `intrinsics` 数组为内参数据，数据对应关系如下：
- fx：481.999753646505
- fy：481.13508765305545
- cx：332.8031113212142
- cy：224.61799309036886

## 4. 标定程序部署

1. 下载 kalibr 到本地，使用下方链接下载即可：

<a href="https://diffrobots.oss-cn-hangzhou.aliyuncs.com/j30-wiki/tools/kalibr-ws.zip" download="kalibr_ws">
    下载 kalibr_ws 程序（zip格式）
</a>

2. 安装依赖：

```bash
sudo apt update

sudo apt-get install -y \
    git wget autoconf automake nano \
    libeigen3-dev libboost-all-dev libsuitesparse-dev \
    doxygen libopencv-dev \
    libpoco-dev libtbb-dev libblas-dev liblapack-dev libv4l-dev

sudo apt-get install -y python3-dev python3-pip python3-scipy \
    python3-matplotlib ipython3 python3-wxgtk4.0 python3-tk python3-igraph

sudo apt-get install python3-catkin-tools python3-osrf-pycommon

sudo apt-get install python3-wxgtk4.0

sudo apt-get install python3-igraph
```

3. 编译工程：

```bash
cd kalibr-ws
catkin_make -DCMAKE_BUILD_TYPE=Release
```
