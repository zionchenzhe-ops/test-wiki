# 维护保养

!!! info "📖 本章导读"
    * 无人机作为精密的飞行设备，定期维护保养对确保性能和延长使用寿命至关重要
    * 本章内容包括：日常清洁与保养、电池保养与报废处理、充电器与遥控器保养

## 清洁指南

1. 机身、桨叶清洁：使用柔软干布擦拭机身表面，去除灰尘和污渍。
2. 传感器清洁：使用柔软干布清洁激光雷达、光流等，确保正常工作。

## 无人机保养

1. 日常使用后，待无人机电机冷却至常温再进行清洁，禁止高温状态下立即清洁。
2. 检查螺旋桨：若螺旋桨有裂痕、变形或损伤，请立即更换。
3. 检查桨保是否松动，如有松动及时紧固。
4. 检查机臂、机身机尾等部分，如有损伤或磨损，请立即更换；检查螺丝并紧固。
5. 清洁完成后，将无人机放置于通风干燥处，最好使用原装包装盒来存储。

## 电池保养与维护

1. 电池充电：请使用官方标配充电器充电，严禁使用非官方充电器；充电时应该放置在空旷安全的地方。
2. 电池使用：使用过程中避免电池过充、过放，以延长电池使用寿命。
3. 闲置与存储：长期存放时，需将电池从机身取下，电量保持在 40%–60%（单片电芯电压 3.7–3.8V），严禁满电或亏电长期静置。
4. 存放环境：请置于干燥、通风、阴凉处，并存放在电池防爆柜内；远离阳光直射、高温、易燃易爆物品、腐蚀性物质及强磁环境。
5. 长期存放维护：禁止将电池安装在无人机上长期存放；存放期间每 1 个月进行一次充放电循环，并将电量重新保持在 40%–60%。
6. 接口防护：电池接口需远离金属导电材料，防止正负极短接。
7. 放置要求：多块电池不建议堆叠存放，勿在电池上放置重物。
8. 低温环境使用：寒冷环境下使用前，需将电池预热至室温，避免在极低温度下充电。

## 电池报废处理

1. 电池出现鼓包、漏液、发烫、异味、严重变形或无法充放电等异常情况时，应立即停止使用，判定为报废电池。
2. 报废电池严禁继续充电、使用或私自拆解，避免发生起火、爆炸等安全事故。
3. 报废电池需单独存放于阻燃、防爆、通风的专用容器内，与正常电池分区隔离，远离高温、明火及易燃易爆物品。
4. 严禁将报废电池随意丢弃、掩埋或投入普通垃圾桶，避免造成环境污染及安全隐患。
5. 报废电池统一收集后，交由具备资质的专业回收机构或正规回收网点进行无害化、资源化处理。

## 充电器与遥控器保养与维护

1. 遥控器：日常使用后，用干净湿布擦拭遥控器表面，将遥控器充满电，放置于阴凉干燥的区域。
2. 遥控器：禁止长时间上电待机，使用后应及时关闭电源，定期检查电池电量以防过放，充电时仅限使用原厂配套充电器，且须有人值守，充满电后立即拔掉充电器。
3. 无人机电池充电器：仅限使用原厂配套充电器，以保障充电安全与设备使用寿命，充电前需确认充电参数设置正确，充电过程须有人值守、严禁无人值守充电，且建议将设备置于防爆柜内进行充电。
4. 日常检查：定期检查遥控器、充电器的线缆及接口是否完好，确认无破损、无松动后方可使用。

## 危险与危害一览表

| 内容 | 危险/危害类型 | 应对措施 |
| --- | --- | --- |
| 旋转的旋翼造成的人员伤害 | 危险 | 及时就医 |
| 电池意外起火等 | 危险 | 使用沙土或干粉灭火器灭火 |
| 误操作导致无人机坠毁及撞击 | 危险 | 加强培训 |
| 由于无人机动力耗尽或故障导致的坠毁或撞击 | 危险 | 及时关注电池电量，尽量避免超长航线 |
| 废旧电池不当处理对环境产生的危害 | 危害 | 到当地指定地点进行处置 |
